# 面具之下 · Beneath the Mask

《面具之下》是一款以三星堆文化意象为灵感创作的网页严肃游戏。玩家通过扫描、修复和鉴定面具，理解表情与情绪并非只有一种解释：严肃不一定是生气，注视可能源于警觉与保护，微笑也可能与紧张并存，沉默则可能来自疲惫或难以表达。

## 游戏内容

- 第一关「威严面具」：严肃不等于愤怒
- 第二关「纵目面具」：凝视也可能意味着警觉与守护
- 第三关「含笑面具」：微笑可以与紧张和勇气同时存在
- 第四关「无言面具」：沉默背后也可能有复杂感受
- 支持横屏布局、碎片扫描、拖拽修复、多选鉴定与逐关解锁

## 本地运行

这是一个无需构建步骤的静态网页项目。建议在项目目录启动本地 HTTP 服务后访问：

```bash
python -m http.server 8080
```

然后打开 `http://localhost:8080/`。

游戏中的人物、面具、情境和叙事均为受三星堆文化启发的教育性艺术想象，并非对真实历史人物或事件的复原。
